Exercício 2 - Identificando Cliente, Servidor e Resposta

Site escolhido: YouTube

URL acessada: https://www.youtube.com

Quem é o cliente: O cliente é o navegador utilizado pelo usuário para acessar o YouTube, como Google Chrome, Microsoft Edge ou Firefox.

Quem é o servidor: O servidor é a infraestrutura de servidores responsável por receber a solicitação e fornecer o conteúdo do YouTube.

Qual resposta o servidor entrega: O servidor entrega os conteúdos solicitados pelo usuário, como a página do site, vídeos, imagens e outras informações necessárias para o funcionamento da plataforma.

Protocolo utilizado: HTTPS.
